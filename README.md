# 🇵🇹 Sobre o Projeto

Painel de conexão para servidor FiveM com atualização automática a cada 1 minuto, apresentando o estado da cidade (🟢 Online / 🔴 Offline), a quantidade de jogadores conectados 👥 e o IP do servidor 🌐.

🚀 Inclui um botão de conexão rápida para entrar automaticamente na cidade através do FiveM, acompanhado por um botão de acesso direto à loja 🛒, proporcionando uma experiência simples, rápida e intuitiva para os jogadores.

---

# 🇬🇧 About the Project

A FiveM server connection panel with automatic updates every 60 seconds, displaying the city's status (🟢 Online / 🔴 Offline), the current number of connected players 👥, and the server IP address 🌐.

🚀 Features a quick-connect button that allows players to join the city directly through FiveM, alongside a dedicated store button 🛒 for easy access to the server's shop, providing a smooth, fast, and user-friendly experience.
